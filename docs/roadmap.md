# Symbio 开发路线图

## Phase 1 — 核心骨架 (Foundation)

> 目标：搭建项目基础结构，实现基于动态 DAG 的最小可用调度引擎

### 1.1 项目初始化
- [ ] 目录结构规划与 Pydantic 全局配置管理
- [ ] 基于 Loguru 的异步日志系统集成
- [ ] Typer CLI 入口框架搭建

### 1.2 调度中枢与动态引擎 (Orchestrator & INFRA)
- [ ] 任务意图解析器与基于 LLM 的复杂度评估器
- [ ] 动态 DAG 引擎基础版实现（支持运行时拓扑重构与节点的动态增删）
- [ ] 智能上下文剪枝器（ContextPruner）与 Prompt Cache 对齐

### 1.3 防御性网关 (Guardrails)
- [ ] 预算熔断与高危动作拦截网关（Guardrail）
- [ ] 基于令牌桶/漏桶算法的异步流控器（RateLimiter）
- [ ] 状态持久化与断点续传检查点（Checkpoint）

### 1.4 基础 Agent
- [ ] Agent 基类（BaseAgent）与能力声明注册中心
- [ ] 内置通用 Agent 实例与生命周期管理

**里程碑：** CLI 下能接收复杂任务、动态生成并执行 DAG 拓扑、在突发大流量或超预算时安全熔断/流控。

---

## Phase 2 — 多 Agent 体系与共识进化 (Multi-Agent & Consensus)

> 目标：实现 SubAgent 派发、多代理协作与群体决策机制

### 2.1 SubAgent 动态派发
- [ ] 宏观任务拆解器
- [ ] SubAgent 的动态创建、生命周期托管与销毁机制
- [ ] 上下文与变量流在父子 Agent 间的安全传递

### 2.2 群体决策与辩论
- [ ] 多代理共识辩论机制（Proposer / Critic / Refiner 闭环架构）
- [ ] 异步消息总线（Message Bus）与多智能体通信协议

### 2.3 错误处理与容错
- [ ] 链路故障自动重试与自适应降级执行策略

**里程碑：** 主 Agent 能将复杂任务拆解，派发给多个 SubAgent 并行执行，遇到模糊或高难度决策能通过内部协作辩论达成共识。

---

## Phase 3 — 认知图谱记忆系统 (Cognitive Memory)

> 目标：实现 LanceDB 向量检索与本体理论（Ontology）双驱动的长期记忆

### 3.1 向量存储基建 (LanceDB)
- [ ] LanceDB 嵌入式连接管理与 Apache Arrow 向量表设计
- [ ] 混合检索策略（语义 Embedding + 标量过滤）

### 3.2 短期与工作记忆
- [ ] 会话上下文滑动窗口与基于语义的关键信息实时提取

### 3.3 本体图谱引擎 (Ontology Engine)
- [ ] 核心概念元模型设计（T-Box：代码、用户偏好、环境契约）
- [ ] 异步进化流中的 A-Box 实体-关系-属性自动化抽取机制
- [ ] 本地图谱拓扑符号推理引擎（利用传递性、继承性实现零 Token 推理）

### 3.4 记忆净化策略
- [ ] 长期记忆的重要度评分与时效性修剪机制
- [ ] 跨上下文的实体对齐与记忆合并去重

**里程碑：** Agent 拥有纯净、具备逻辑学底蕴的长效记忆，能通过图关联把破碎的向量片段编织成全景网，具备常识联想能力。

---

## Phase 4 — 工具层与环境沙箱 (Tools & Sandbox)

> 目标：构建原生兼容 MCP 协议、安全可控的工具执行层

### 4.1 工具流基建
- [ ] 工具基类定义与工具注册中心（ToolRegistry）
- [ ] Model Context Protocol (MCP) 协议原生对接与标准工具挂载

### 4.2 内置核心工具链
- [ ] Claude Code (Harness) 深度集成与高效调用
- [ ] 异步长连接 Shell 命令执行器（支持流式输出监听）
- [ ] 自动化 Git 工作流与高级文件 AST 解析引擎

### 4.3 物理安全防护
- [ ] 动态黑白名单拦截拦截机制
- [ ] 环境隔离沙箱化运行支持（超时、资源限制与异常阻断）

**里程碑：** Agent 能无缝调用海量开源 MCP 工具，并在极端无网或隔离环境下安全、不受限地长出手脚做事情。

---

## Phase 5 — 接入层与动态介入 (Interface & HITL)

> 目标：构建全端交互入口与动态人类介入总线

### 5.1 人类介入总线 (HITL)
- [ ] 高危动作自动挂起与状态冻结
- [ ] 异步 IM 授权总线（微信/飞书/QQ 审批卡片交互机制）

### 5.2 可观测性 (Observability)
- [ ] 时空运行轨迹图 — 类分布式链路追踪 (Trace)，可视化 Agent 派发、等待、Token 消耗
- [ ] 记忆快照回放 — 任务失败节点断点恢复，复现当时记忆状态
- [ ] Token 消耗热力图 — 可视化各 Agent/工具的 Token 消耗分布

### 5.3 多端呈现
- [ ] 终端交互控制台（Typer + Prompt_toolkit + Rich）
- [ ] 轻量化服务端封装（FastAPI RESTful + WebSocket 流式推送）
- [ ] 现代化 Web 监控面板（Next.js + shadcn/ui）与本地跨平台桌面端（Tauri 2.0）

**里程碑：** 支持多端无缝交互，运行轨迹全程可视，高危操作时管理员可通过手机 IM 异步一键审批或下达修改指令。

---

## Phase 6 — 数据飞轮与自我进化 (Data Flywheel & Evolution)

> 目标：运行即沉淀，实现数据反哺与策略自动优化

### 6.1 高质量数据集飞轮 (Data Flywheel)
- [ ] Agent 完整运行轨迹捕获（Thought → Action → Observation → Result）
- [ ] 微调语料自动化清洗、脱敏与标准数据集（Alpaca/ShareGPT）导出

### 6.2 进化与策略优化
- [ ] 显式/隐式用户反馈多维收集系统（SQLite 异步存储）
- [ ] 自动化评测模块（symbio eval）搭建：工具调用、路由准确率回归检测
- [ ] 高频成功路径的 SOP 固化与失败模式库（Root Cause）建设

**里程碑：** 系统越用越聪明，不仅能自动避坑，还能为团队源源不断地沉淀私有高质量微调数据资产。

---

## Phase 7 — 高级企业级特性 (Advanced Production)

> 目标：全天候多用户托管运行能力

### 7.1 事件驱动调度
- [ ] Cron 定时流托管与 Webhook 实时仓库事件监听触发器

### 7.2 企业级安全隔离
- [ ] 多用户认证、动态 RBAC 权限控制与严格的会话/数据空间隔离

**里程碑：** 具备完全的生产级私有化独立部署与 24 小时无人值守托管能力。

---
