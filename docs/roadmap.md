# Symbio 开发路线图

## Phase 1 — 核心骨架 (Foundation)

> 目标：搭建项目基础结构，实现最小可用的调度引擎

### 1.1 项目初始化
- [ ] 目录结构规划
- [ ] 配置管理（YAML/TOML）
- [ ] 日志系统
- [ ] CLI 入口框架

### 1.2 调度中枢 (Orchestrator)
- [ ] 任务解析器
- [ ] 复杂度评估器
- [ ] 模型路由器
- [ ] 任务队列

### 1.3 基础 Agent
- [ ] Agent 基类
- [ ] 内置通用 Agent
- [ ] Agent 生命周期管理

**里程碑：** CLI 下能接收任务、评估复杂度、调用对应模型完成

---

## Phase 2 — 多 Agent 体系 (Multi-Agent)

> 目标：实现 Agent 间协作与 SubAgent 派发

### 2.1 Agent 注册机制
- [ ] Agent 注册中心
- [ ] Agent 能力声明
- [ ] Agent 发现与匹配

### 2.2 SubAgent 派发
- [ ] 任务拆解器
- [ ] SubAgent 创建与销毁
- [ ] 结果汇总与汇报

### 2.3 Agent 通信
- [ ] 消息总线
- [ ] 上下文传递
- [ ] 错误处理与重试

**里程碑：** 主 Agent 能拆解复杂任务，派发给多个 SubAgent 并行执行

---

## Phase 3 — 记忆系统 (Memory)

> 目标：实现基于 LanceDB 的持久化记忆

### 3.1 LanceDB 集成
- [ ] 连接管理
- [ ] 向量表设计
- [ ] 索引策略

### 3.2 短期记忆
- [ ] 会话上下文窗口
- [ ] 滑动窗口压缩
- [ ] 关键信息提取

### 3.3 长期记忆
- [ ] 记忆存储（向量化）
- [ ] 语义检索
- [ ] 记忆更新与遗忘

### 3.4 记忆策略
- [ ] 重要性评分
- [ ] 时效性管理
- [ ] 记忆合并与去重

**里程碑：** Agent 能记住用户偏好、历史对话，并在需要时检索相关记忆

---

## Phase 4 — 工具层 (Tools)

> 目标：构建可扩展的工具执行框架

### 4.1 工具框架
- [ ] 工具基类
- [ ] 工具注册中心
- [ ] 权限管理

### 4.2 内置工具
- [ ] Claude Code 集成
- [ ] Shell 命令执行
- [ ] 文件读写操作
- [ ] Git 工作流
- [ ] HTTP 请求

### 4.3 工具安全
- [ ] 命令白名单/黑名单
- [ ] 执行沙箱
- [ ] 超时控制

**里程碑：** Agent 能安全地调用各种外部工具完成任务

---

## Phase 5 — 接入层 (Interface)

> 目标：支持多种交互方式

### 5.1 CLI 完善
- [ ] 交互式对话
- [ ] 命令补全
- [ ] 历史记录

### 5.2 Web UI
- [ ] 前端框架选型（Next.js）
- [ ] 对话界面
- [ ] 任务监控面板
- [ ] 记忆可视化

### 5.3 Desktop App
- [ ] 框架选型（Tauri）
- [ ] 系统托盘
- [ ] 快捷键唤起

### 5.4 IM 接入
- [ ] QQ（Lagrange.OneBot）
- [ ] 微信（wechaty）
- [ ] 统一消息路由
- [ ] 多平台会话同步

### 6.1 反馈收集

### 6.2 行为优化
- [ ] 策略评估
- [ ] A/B 测试框架

### 6.3 知识沉淀
