# Symbio UI 设计方案

> 方案先行，设计升维。UI 不是附属品，而是 Symbio 与用户交互的唯一窗口。

---

## 1. 设计哲学

### 1.1 核心理念

**"信息密度优先，操作效率至上"**

- **信息密度** — 在有限的屏幕空间内展示最多有价值的信息
- **操作效率** — 减少点击次数，常用操作一键直达
- **视觉层次** — 用色彩、间距、字重区分信息优先级
- **一致性** — 统一的交互模式，降低学习成本

### 1.2 设计原则

| 原则 | 说明 |
|------|------|
| 渐进式复杂度 | 简单场景简单，复杂场景可选 |
| 实时反馈 | 每个操作都有即时视觉反馈 |
| 错误友好 | 错误信息清晰，修复建议明确 |
| 键盘优先 | 支持快捷键，减少鼠标操作 |
| 暗色主题 | 默认暗色，减少视觉疲劳 |

## 3. 核心页面设计

### 3.1 对话页面 (/chat)

**布局：** 三栏布局

```
┌──────────┬────────────────────────────┬──────────┐
│          │                            │          │
│  会话    │      对话内容区域           │  上下文   │
│  列表    │                            │  面板    │
│          │  ┌──────────────────────┐  │          │
│  会话1   │  │ 用户消息             │  │  记忆    │
│  会话2   │  │                      │  │  检索    │
│  会话3   │  │ Agent 回复           │  │  结果    │
│  ...     │  │                      │  │          │
│          │  │ 工具调用             │  │  工具    │
│          │  │                      │  │  执行    │
│          │  └──────────────────────┘  │  日志    │
│          │                            │          │
│          │  ┌──────────────────────┐  │          │
│          │  │ 输入框 + 快捷操作     │  │          │
│          │  └──────────────────────┘  │          │
└──────────┴────────────────────────────┴──────────┘
```

**核心组件：**

| 组件 | 说明 |
|------|------|
| 会话列表 | 左侧栏，显示历史会话，支持搜索、分组、置顶 |
| 消息气泡 | 支持 Markdown、代码高亮、表格、图片 |
| 工具调用卡片 | 折叠式展示工具调用详情（输入/输出/耗时） |
| 上下文面板 | 右侧栏，展示当前会话的记忆检索结果、工具执行日志 |
| 输入框 | 支持多行、@提及工具、附件上传、快捷命令 |
| 快捷操作栏 | 常用操作按钮（清空会话、导出、分享） |

**交互细节：**

- 消息流式输出，实时显示 Token 消耗
- 工具调用支持展开/折叠，显示执行状态（进行中/成功/失败）
- 支持消息重试、编辑、删除
- 支持会话分支（从某条消息重新开始）
- Ctrl+Enter 发送，Shift+Enter 换行

### 3.2 任务监控页面 (/tasks)

**布局：** 双栏布局

```
┌─────────────────────────────────────────────────────────────┐
│                      任务列表 + 过滤器                        │
├────────────────────────────────┬────────────────────────────┤
│                                │                            │
│        DAG 可视化区域           │      任务详情面板           │
│                                │                            │
│    ┌───┐     ┌───┐            │  任务 ID: xxx              │
│    │ A │────▶│ B │            │  状态: 运行中              │
│    └───┘     └───┘            │  模型: claude-sonnet       │
│       │                       │  Token: 1234 / 5000       │
│       ▼                       │  耗时: 2m 30s              │
│    ┌───┐     ┌───┐            │                            │
│    │ C │────▶│ D │            │  执行日志:                 │
│    └───┘     └───┘            │  [10:30:15] 开始执行       │
│                                │  [10:30:45] 工具调用成功   │
│                                │  [10:31:20] 等待审批       │
│                                │                            │
├────────────────────────────────┴────────────────────────────┤
│                      实时日志流                              │
└─────────────────────────────────────────────────────────────┘
```

**核心组件：**

| 组件 | 说明 |
|------|------|
| 任务列表 | 支持按状态/时间/模型过滤，支持批量操作 |
| DAG 可视化 | 基于 React Flow 的交互式图可视化 |
| 任务详情面板 | 展示任务元数据、执行日志、Token 消耗 |
| 实时日志流 | 底部区域，实时滚动显示系统日志 |

**DAG 节点设计：**

```
┌─────────────────────────┐
│  ● 节点名称              │  ← 状态指示灯（绿/黄/红/灰）
│  Agent: CodeAgent       │  ← 执行 Agent
│  模型: claude-sonnet     │  ← 使用模型
│  Token: 523             │  ← Token 消耗
│  耗时: 12s              │  ← 执行时间
└─────────────────────────┘
```

**交互细节：**

- DAG 节点支持点击展开详情
- 支持缩放、平移、自动布局
- 节点状态实时更新（动画效果）
- 支持暂停/恢复/取消任务
- 支持断点续传（从失败节点重新开始）

## 5. 交互流程

### 5.1 对话流程

```
用户输入消息
    │
    ▼
前端发送到后端 API
    │
    ▼
后端创建任务，返回任务 ID
    │
    ▼
前端建立 WebSocket 连接
    │
    ▼
后端流式推送消息
    ├─ Agent 思考过程
    ├─ 工具调用请求
    ├─ 工具执行结果
    └─ 最终回复
    │
    ▼
前端实时渲染
    ├─ 显示思考过程（可折叠）
    ├─ 显示工具调用卡片
    └─ 显示最终回复
    │
    ▼
用户可选择：
    ├─ 继续对话
    ├─ 重试消息
    ├─ 编辑消息
    └─ 分支对话
```

### 5.2 任务执行流程

```
任务创建
    │
    ▼
DAG 生成（可视化）
    │
    ▼
节点执行
    ├─ Agent 选择
    ├─ 模型选择
    ├─ 工具调用
    └─ 结果返回
    │
    ▼
状态更新（实时）
    ├─ 节点颜色变化
    ├─ 进度条更新
    └─ 日志滚动
    │
    ▼
任务完成/失败
    ├─ 成功：显示结果摘要
    └─ 失败：显示错误详情 + 重试选项
```

### 5.3 模型配置流程

```
点击"添加模型"
    │
    ▼
选择供应商（Anthropic/OpenAI/Ollama/自定义）
    │
    ▼
填写配置
    ├─ API Key
    ├─ Base URL（可选）
    └─ 模型参数
    │
    ▼
测试连接
    ├─ 成功：显示绿色对勾
    └─ 失败：显示错误信息
    │
    ▼
保存配置
    │
    ▼
配置任务绑定策略
    ├─ 代码生成 → 模型 A
    ├─ 简单问答 → 模型 B
    └─ 复杂推理 → 模型 C
```

## 11. 动画与过渡效果

### 11.1 核心动画原则

| 原则 | 说明 |
|------|------|
| 有意义的动画 | 动画必须传达状态变化，而非装饰 |
| 快速响应 | 动画时长 150-300ms，不超过 500ms |
| 流畅曲线 | 使用 ease-out 或 spring 曲线 |
| 可关闭 | 尊重用户的减少动画偏好 |

### 11.2 核心动画清单

| 场景 | 动画效果 | 时长 |
|------|----------|------|
| 页面切换 | 淡入淡出 + 轻微位移 | 200ms |
| 消息出现 | 从底部滑入 + 淡入 | 150ms |
| 工具调用展开 | 高度展开 + 淡入 | 200ms |
| DAG 节点状态变化 | 颜色渐变 + 脉冲效果 | 300ms |
| 加载状态 | 骨架屏 + 脉冲动画 | 持续 |
| 按钮点击 | 缩放 0.95 + 涟漪效果 | 100ms |
| 侧边栏展开/收起 | 宽度变化 + 内容淡入 | 200ms |
| 模态框出现 | 缩放 0.95 → 1 + 淡入 | 200ms |
| Toast 通知 | 从右上角滑入 + 自动消失 | 3s |
| 拖拽反馈 | 轻微放大 + 阴影增强 | 100ms |

### 11.3 流式消息动画

```
消息输入中...
├─ 光标闪烁动画 (每 500ms 闪烁一次)
├─ "思考中..." 文字动画 (点点点循环)
└─ 进度条动画 (从左到右，无限循环)

消息输出中...
├─ 文字逐字出现 (每 50ms 一个字)
├─ 代码块高亮延迟 (等代码完整后一次性高亮)
└─ 工具调用卡片展开动画 (从折叠到展开)
```
